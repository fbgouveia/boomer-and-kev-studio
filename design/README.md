# Design — Boomer & Kev (fonte única)

Ordem do Felipe, 29/10/2026. Vale para qualquer LLM (Claude, Codex, Gemini, Open Design).

## Regras

1. **Uma plataforma só: o Studio.** Nada de página, painel ou app avulso. Revisões, painéis e
   telas novas nascem para o Studio ou não nascem.
2. **O Claude é o dono do design.** Ele produz/cura os designs (Claude Design / Open Design) e
   mantém este repositório. Outra LLM que tocar em design avisa no log que o trabalho foi dela.
3. **Layout congelado.** Nenhuma mudança visual no Studio sem aprovação explícita do Felipe
   (ver `AGENTS.md` da raiz). Fluxo: desenhar → Felipe aprova → só então vira código.
4. **Todo design é registrado em [`LOG.md`](LOG.md)**, inclusive o feito no Open Design ou por
   outra LLM: data, quem fez, ferramenta, onde está, status. Sem registro = não existe.
5. **Arte aprovada fica aqui** (`design/aprovados/`), com o mesmo nome citado no log.
   Rascunhos ficam onde a ferramenta salvou, mas o log aponta o caminho.

## Marca (única — não criar paleta própria)

- Primária: `#FF5F1F` (Signal Orange). Fundo: `#000000` / `#0d0d0d`.
- Estilo: Brutalist Neural Glass — bordas sólidas laranja de 4px, overlays HUD com blur.
- **Proibido:** qualquer tom de roxo/violeta; paletas paralelas (ex.: o âmbar do painel de 27/10).
- Personagens: as masters em `public/assets/` são a referência; nenhuma arte muda rosto,
  anatomia ou figurino original sem aprovação.

## Antes de qualquer trabalho de design

Ler este arquivo e o fim do `LOG.md`. Ao terminar, acrescentar uma linha no log.
