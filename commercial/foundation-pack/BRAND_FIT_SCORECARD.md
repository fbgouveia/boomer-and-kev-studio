# INTERNAL BRAND FIT SCORECARD

Score each dimension from 0 to 5.

| Dimension | 0 | 5 | Score |
|---|---|---|---:|
| Audience fit | Irrelevant or harmful | Natural audience value | |
| Comic potential | Static logo placement | Product creates visible conflict | |
| Demonstrability | Cannot show proof | Benefit is visible in action | |
| Claims safety | Unclear/high-risk claims | Simple, substantiated truth | |
| Creative freedom | Script dictated by brand | Characters remain authentic | |
| Economics | Negative/unclear margin | Strong margin and payment terms | |
| Recurrence | One-off with no learning | Clear renewal/campaign path | |
| Reputation | High trust risk | Strengthens the property | |
| Operational load | Disproportionate complexity | Fits current production system | |

Maximum: 45.

## Decision bands

- **36–45 — pursue:** strong strategic fit;
- **28–35 — qualify:** proceed only after resolving weak dimensions;
- **20–27 — exceptional approval:** revenue does not override brand risk;
- **0–19 — decline.**

## Automatic escalation

Regardless of score:

- gambling or wagering;
- alcohol;
- financial products, credit or crypto;
- health, therapeutic or supplement claims;
- politics;
- child-directed products;
- adult or restricted categories;
- perpetual IP rights;
- broad exclusivity;
- request to hide the commercial relationship.
